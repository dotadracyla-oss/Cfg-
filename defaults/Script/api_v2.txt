Unix Lua API 2.0 - extensions (API names are English)
render.drag(id, default_x, default_y, width, height) -> x, y
Use returned coordinates for HUD drawing. Drag while menu or Lua console is open.
Positions persist per script and HUD id; 32 regions maximum; clamped to the screen.
render.opacity(value) -- 0..1, multiplies alpha for subsequent drawing calls.
render.layer("background" | "foreground") -- background draws below Unix UI.
Both reset at each callback. render colors use {r,g,b,a} in 0..255.
Alpha 0 is invisible, 128 is translucent, 255 is opaque. No HUD background is implicit.
http.request(url, {method="GET", body="", headers={Accept="application/json"}}) -> request_id
Methods: GET POST PUT PATCH DELETE HEAD OPTIONS. HTTP and HTTPS, normal TLS verification.
http.poll(request_id) -> nil while pending; response table once complete.
Response: {ok, status, body, headers, error}. Unknown/consumed ID: nil, error.
Maximum 8 outstanding requests per script, request body 256 KiB, response 1 MiB.
Network runs on workers. Pending workers are joined when the script unloads.
browser.open(url, mode="2d") -> queued (boolean). Embedded WebView2; HTTP/HTTPS only.
Modes: "2d" on-screen window, "3d" Unity world surface, "both" shared page in both.
browser.close() hides both surfaces and stops page navigation/audio.
browser.place(x,y,z,yaw=0,width=2.4,height=1.35) sets the world panel position in Unity units.
3D opening automatically places the panel 2.5 units in front of the current player camera.
browser.status() -> {running, ready, frames, title, error}; ready means WebView2 is ready.
One shared page/profile for all scripts. Call mutations from callbacks.
2D: address bar, back, reload, close, mouse, wheel and keyboard. 3D button places the panel ahead.
3D uses a real Unity quad, an external D3D11 shader-resource view and an unlit material
(Universal Render Pipeline/Unlit, falling back to Unlit/Texture); scene depth applies.
Page frames are captured as JPEG at 15 fps for the 2D window and 10 fps for the world
panel; nothing is captured while neither surface is visible. browser.status().error also
carries 3D progress text ("3D: waiting for the first page frame", "3D: surface at ...").
Click a world panel to focus input; Escape releases keyboard focus.
Requires Microsoft Edge WebView2 Runtime. Chromium keeps normal TLS verification.
The browser capture runs on a separate STA thread and is uploaded at up to 15 frames/second.
Native Unity panel rendering/interaction must be verified in-game for the installed build.
features.list() -> {FeatureName={SettingName=value,...},...}
features.get("GodMode", "Enabled") -> value or nil
features.set("GodMode", "Enabled", true) -> true
Feature colors use normalized RGBA {0..1,0..1,0..1,0..1}; unlike render colors.
features.actions() -> available stable action IDs
features.trigger("action_Teleport_Truck") -> known_action
Call HTTP, browser and feature mutations from callbacks, not at script top level.
Actions still require the relevant game state/host permissions.
Native Unix settings remain accessible through settings.list/get/set.
