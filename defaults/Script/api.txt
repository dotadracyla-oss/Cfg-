UNIX LUA API - v2.0
Extensions: see api_v2.txt (HTTP/HTTPS, browser, features, transparent HUD).
==================

Getting started
---------------
Lua 5.4.9 is embedded in Unix; no external runtime is needed.
Reference: https://www.lua.org/manual/5.4/manual.html
Scripts: C:\Unix\Script. Configurations: C:\Unix\Config.
Open Unix > Lua, select a UTF-8 .lua file, then Load.
Stop releases its VM. Reload replaces it only after a successful load.
Refresh scripts rescans the folder. Autorun loads it next session.
Reload on file change watches the file. Subdirectories/symlinks are not scanned.
Filenames support ASCII letters, digits, spaces, underscores and hyphens.
Loading a script does not reload the game DLL.

The first normal injector launch downloads the default config, three scripts
and this document from GitHub. Completion marker: C:\Unix\.github-defaults-v1.
Existing user files are preserved. Failed downloads are retried next launch;
embedded defaults provide an offline fallback. A private repository requires
read credentials. No GitHub token is embedded. Examples do not autorun.
The Lua runtime also refreshes api.txt from its embedded documentation.

Example:
    local enabled = ui.checkbox("enabled", "My text", true)
    client.on("on_frame", function(dt)
        if enabled:get() then
            render.text(30, 160, render.color(160, 140, 255), "Hello Unix", 18)
        end
    end)

client
------
client.on(event_name, callback): register at file scope; eight handlers/event.
Events, in registration order:
  on_frame(dt): frame logic/drawing, also with menu closed; dt is seconds.
  on_menu(): after the open menu is drawn. Controls are drawn automatically.
  on_hunt_start(event), on_hunt_end(event): observed hunt transitions.
    event.duration is observed elapsed seconds; partial means observation
    started mid-hunt; test indicates a test event. Existing active hunts at
    runtime startup do not produce a new hunt-start event.
  on_ghost_event(event): event.test and event.partial indicate test/already active.
  on_incense(event): newly observed incense use.
  on_ui_change(id,value): changed control; rapid changes may be coalesced.
  on_shutdown(): Stop, successful Reload or shutdown; no drawing. Not called
    for a script stopped by a fatal error. Shared settings are not rolled back.
Events use existing telemetry. Enable Ghost information/Hunt timer for hunt
data and Notifications for ghost events. Check validity flags.
client.log(...) / print(...): informational console message.
client.warn(...): warning; execution continues.
client.error(...): error message and open console; execution continues.
error(message): Lua exception; stops this script, leaving other VMs running.
client.time() -> monotonic Windows time, seconds (not Unix timestamp).
client.fps() -> smoothed ImGui rendering FPS.
client.info() -> {name,version,lua_version,memory,memory_limit,last_ms}.
  Memory is bytes; last_ms is the last callback duration.
client.after(seconds,callback) -> timer_id: once.
client.every(seconds,callback) -> timer_id: repeating.
client.cancel(timer_id) -> boolean; self-cancellation is supported.
  Intervals: 0.01..3600 seconds; 64 timers/script. Runs on frames, not threads.
  Missed intervals are not replayed; Stop/Reload removes old timers.
  Draw in on_frame/on_menu, not timer callbacks. Avoid logging every frame.

ui
--
Create controls once at file scope, not inside callbacks; 64 controls/script.
IDs: unique ASCII letters/digits/underscore/hyphen, maximum 48 characters.
Labels: maximum 96 UTF-8 bytes.
ui.checkbox(id,label,default_boolean) -> control
ui.slider(id,label,default_number,min,max) -> control
  min < max; finite values in -100000..100000.
ui.combo(id,label,items,default_index=1) -> control
  1..32 strings; Lua indices start at 1.
ui.color(id,label,rgba) -> control; rgba={r,g,b,a}, each channel 0..255.
ui.button(id,label) -> control; get() consumes the click; next get() is false.
control:get() -> boolean | number | index | rgba
control:set(value): validated type/range; color reads return fresh tables.
Saved control values override defaults and are clamped to changed ranges.
Button clicks are not persisted. Right-click opens the bind editor.

render
------
Draw only inside on_frame/on_menu. Drawing lasts one frame; repeat each frame.
Pixel origin: top-left, X right, Y down. Projected game x/y are normalized:
pixel_x=x*width, pixel_y=y*height.
render.screen() -> width,height
render.color(r=255,g=255,b=255,a=255) -> {r,g,b,a}
render.text(x,y,color,text,size=current_font_size)
render.measure_text(text,size=current_font_size) -> width,height
  UTF-8 text, maximum 1024 bytes; size 6..72 pixels.
render.line(x1,y1,x2,y2,color,thickness=1)
render.rect(x,y,width,height,color,rounding=0,thickness=1)
render.rect_filled(x,y,width,height,color,rounding=0)
render.circle(x,y,radius,color,thickness=1)
render.circle_filled(x,y,radius,color)
  Thickness 0.1..20; rectangle sizes 0..10000; radius 0..5000.
  Maximum 1024 draw calls per callback dispatch per script.

game
----
Tables are copies; editing them does not modify the game. Check valid/visible
and individual validity flags. Data depends on enabled Unix features.
visible means projected on screen, not visible through an unobstructed ray.
game.status() -> {camera,ping,sanity,fear,sanity_valid,sampled_at,ticks,
                  ghost_room,menu_open}
  ping: milliseconds, -1 unknown; sanity: 0..100; fear: 100-sanity;
  sampled_at: seconds on client.time() scale; ticks: sample count.
game.ghost() -> {valid,type,activity,speed,speed_valid,hunting,hunt_seconds,
                 partial_hunt}
  speed: meters/second; hunt_seconds: observed elapsed hunt time.
game.players() -> array of {name,actor,sanity,fear,valid,visible,x,y,distance}
game.room() -> {valid,name,temperature,temperature_valid,power_valid,power_on,
                switches,switches_on}; temperature is Celsius.
game.objects() -> array of {name,kind,x,y,distance,blocked}
  kind: "bone", "cursed", "exit", "hiding", "unknown".
  Returns projected Unix markers, not every Unity object.
game.ghost_room() -> {visible,x,y,distance}; marks the room, not the moving ghost.
game.incense() -> {available,used_at,elapsed}
  used_at: client.time() scale, zero if unknown. Elapsed time does not guarantee
  protection against a particular ghost. All distances are meters.
No raw game pointers or separate memory scanning are exposed.

settings
--------
settings.get(name) -> boolean | number | nil (unknown setting)
settings.set(name,value): exact type/range checked; invalid values raise errors.
settings.list() -> array of {name,type,min,max}
Booleans require true/false; integer fields require whole numbers.
Changes apply through existing Unix logic. Use Save or Auto Save to persist.
Color fields: ui_accent0..3, skeleton_color0..3, map_tint0..3,
lighting_color0..3, crosshair_color0..3; channels 0..1, unlike ui/render colors.
ui_language: 0=English (default), 1=Russian. Script text is controlled by the
script; check settings.get("ui_language") for your own translations.
ui_theme: 0=Night, 1=Light; ui_menu_key: Windows virtual-key code.
crosshair_style: 0=67, 1=Cross, 2=Reference.
Legacy speed_bind/skeleton_bind fields remain for compatibility; current
menu bindings use the right-click editor with Hold/Toggle modes.

input
-----
input.down(vk) -> boolean: held.
input.pressed(vk) -> boolean: new press on this frame.
vk: Windows virtual-key code 1..255. Examples: 0x2D Insert, 0x78 F9,
0x10 Shift, 0x11 Ctrl, 0x12 Alt, 0x20 Space, 0x41 A, 0x05 Mouse4, 0x06 Mouse5.
Input is disabled when the game lacks focus or text input is active.
A deferred script can miss a pressed edge; use down for held input.

storage
-------
storage.get(key,default=nil) -> boolean | number | string | default
storage.set(key,value): nil deletes. No tables/functions.
Key: maximum 64 bytes. Value: boolean, finite number -1e12..1e12, or string
up to 2048 bytes. Up to 192 entries/script, including automatic control state.
Writes are debounced for approximately 750 ms and flushed at Stop.
State: C:\Unix\Script\state\<script>.lua.ini
Autorun/watch policy: C:\Unix\Script\manager.ini
Renaming a script changes its storage identity.

Console and limits
------------------
Lua > Open console opens the separate console; errors open it automatically.
Errors only/Search filter entries. Copy copies visible text; Export logs
writes C:\Unix\Script\logs\<script>.lua.log. Clear does not restart a script.
History: 256 entries/script, up to 16384 characters/message. Errors include
filename, line, callback/timer phase and stack traceback. Failed Reload keeps
the working VM and both versions' logs.
Each script has its own VM, globals, callbacks and storage.
Limits: 32 scripts, 512 KiB source, 8 MiB VM memory with 64 KiB argument headroom,
100000 instructions and roughly 5 ms/dispatch; 64 controls, 64 timers,
16 pending events. Frame/menu scheduling targets 8 ms with round-robin fairness.
The hook checks every 1000 instructions and cannot interrupt a running C call.
These are execution budgets, not a strict frame-time guarantee.
Available: base, math, string, table, utf8.
Unavailable: io, os, package, debug, coroutine, require, dofile, loadfile, load,
collectgarbage, pcall, xpcall, FFI and arbitrary process/file access.
HTTP/HTTPS and browser URL opening are available through the API v2 modules.
Use storage for persistence and client.after/every for delayed work.
Scripts execute on the rendering thread; do not busy-wait.

Build and sources
-----------------
Visual Studio: Release | x64. Lua is compiled as C++ for exception unwinding.
src/scripting/runtime.cpp: lifecycle, budgets, events, timers, persistence.
src/scripting/api.cpp: all API modules.
src/ui/portfolio/pages/lua_page.cpp: manager and console.
src/scripting/bundled_examples.hpp: embedded examples/documentation.
Offline previews/tests do not validate live game telemetry.

Unix Lua API 2.0 - extensions (API names are English)
render.drag(id, default_x, default_y, width, height) -> x, y
Use returned coordinates for HUD drawing. Drag while menu or Lua console is open.
Positions persist per script and HUD id; 32 regions maximum; clamped to the screen.
render.opacity(value) -- 0..1, multiplies alpha for subsequent drawing calls.
render.layer("background" | "foreground") -- background draws below Unix UI.
Both reset at each callback. render colors use {r,g,b,a} in 0..255.
Alpha 0 is invisible, 128 is translucent, 255 is opaque. No HUD background is implicit.
http.request(url, {method="GET", body="", headers={Accept="application/json"}}) -> request_id
Methods: GET POST PUT PATCH DELETE HEAD OPTIONS. HTTP and HTTPS, normal TLS verification.
http.poll(request_id) -> nil while pending; response table once complete.
Response: {ok, status, body, headers, error}. Unknown/consumed ID: nil, error.
Maximum 8 outstanding requests per script, request body 256 KiB, response 1 MiB.
Network runs on workers. Pending workers are joined when the script unloads.
browser.open(url, mode="2d") -> queued (boolean). Embedded WebView2; HTTP/HTTPS only.
Modes: "2d" on-screen window, "3d" Unity world surface, "both" shared page in both.
browser.close() hides both surfaces and stops page navigation/audio.
browser.place(x,y,z,yaw=0,width=2.4,height=1.35) sets the world panel position in Unity units.
3D opening automatically places the panel 2.5 units in front of the current player camera.
browser.status() -> {running, ready, frames, title, error}; ready means WebView2 is ready.
One shared page/profile for all scripts. Call mutations from callbacks.
2D: address bar, back, reload, close, mouse, wheel and keyboard. 3D button places the panel ahead.
3D uses a real Unity quad, external D3D11 texture and Unlit/Texture material; scene depth applies.
Click a world panel to focus input; Escape releases keyboard focus.
Requires Microsoft Edge WebView2 Runtime. Chromium keeps normal TLS verification.
The browser capture runs on a separate STA thread and is uploaded at up to 15 frames/second.
Native Unity panel rendering/interaction must be verified in-game for the installed build.
features.list() -> {FeatureName={SettingName=value,...},...}
features.get("GodMode", "Enabled") -> value or nil
features.set("GodMode", "Enabled", true) -> true
Feature colors use normalized RGBA {0..1,0..1,0..1,0..1}; unlike render colors.
features.actions() -> available stable action IDs
features.trigger("action_Teleport_Truck") -> known_action
Call HTTP, browser and feature mutations from callbacks, not at script top level.
Actions still require the relevant game state/host permissions.
Native Unix settings remain accessible through settings.list/get/set.
